How can we help?

Need help with VizoChat? Check the information below or contact our support team.

🎥

Random Chat

Click Start Random Chat to find another available user for a 1-to-1 video chat.

❤️

Valid Likes

Only one Like can be given during a chat. The receiver must stay connected for 10 seconds after the Like for it to become valid.

🏆

Top 20

The Top 20 leaderboard is based on the total number of valid Likes received by users.

🚨

Report

If another user breaks the rules, you can report them during the chat.

Important Rules

  • Guests can use up to 10 matches.
  • After 10 guest matches, Google login is required.
  • Only one Like is allowed per chat session.
  • A Like becomes valid only after the receiver stays connected for 10 seconds.
  • Each valid Like gives the receiver ₹2.
  • Five reports within one hour can result in an automatic 23-day ban.
